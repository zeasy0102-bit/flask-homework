
# Flask Web Application - Lab Assignment

## Description
This project is a Flask web application developed for a
Python programming lab assignment.

## Task 1
- Flask application setup
- Dynamic routes with names
- Square calculation
- Debugging with Flask

## Task 2
- HTML templates using Jinja2
- Dynamic welcome pages
- Conditional statements
- Displaying lists with loops

## Assignment
A multiplication route that accepts two integers
and displays their product using an HTML template.

Example:
`/multiply/3/4`

Expected result:
`3 × 4 = 12`

## Installation
```bash
pip install -r requirements.txt
```

## Run Task 1
```bash
python app1.py
```

## Run Task 2 and Assignment
```bash
python app2.py
```
